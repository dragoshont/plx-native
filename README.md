# PlxNative historical archive

> [!IMPORTANT]
> Active development has moved to **[Vemm](https://github.com/dragoshont/vemm)**.
> Use the [Vemm issue tracker](https://github.com/dragoshont/vemm/issues) for
> current work and support.

This repository preserves the inherited PlxNative history, merged pull requests,
and the six Samsung 0.2.x prereleases with their tags, binary assets, checksums,
and matching source links. The historical
[release list](https://github.com/dragoshont/plx-native/releases) and source
tree remain available so existing public links and licence obligations continue
to resolve.

[Samsung 0.2.7](https://github.com/dragoshont/plx-native/releases/tag/samsung-v0.2.7)
remains the historical **Plx** app. Vemm is a separate clean-install app: it
does not update Plx or migrate Plx credentials, settings, or other saved state.

For provenance and licensing, see the
[repository independence record](docs/samsung-repository-independence-plan.md),
[licensing notes](LICENSING.md), [third-party notices](THIRD-PARTY-NOTICES.md),
and [GPL-3.0-or-later licence](LICENSE).
